❓ Help · version v21

🔗 How do I chat with a friend?

Open a room and tap "🔗 Send link" at the top (or Invite). Your friend opens the link, logs in and joins the same room. Everyone chats in real time.

📞 Calls & ✓✓ ticks?

Tap 📞 (voice) or 📹 (video) at the top of a chat. A call card appears and everyone taps Join (opens in a new tab, powered by Jitsi Meet). One ✓ = delivered, blue ✓✓ = seen.

✨ New tools (＋ button)?

Tap ＋ next to the message box for Polls, Stickers, Location and Search in chat. In Settings → Appearance you can change the colour theme and the chat wallpaper.

😀 React / Reply / Delete a message?

Tap any message. Pick an emoji to react, or choose Reply, Copy or Delete (your own messages).

👥 Group / 📢 Community?

⋮ menu → New group or New community. In a community only the admin can send messages.

✨ Status?

Sidebar → Status → ＋. Text or a photo, visible to friends for 24 hours.

🔒 Chat lock?

Open a chat → tap 🔓 and create a PIN. The preview is hidden and the PIN is needed to open it.

🗂 Archive / ⭐ Favourite?

Use the 🗂 and ☆ buttons at the top of a chat. View them with the chips above the chat list.

🧹 Clear / Delete?

⋮ at the top of the chat → Clear chat or Delete. This only affects you.

🤖 Glide-Chat AI?

A helper built into the app. Ask it about the app, jokes, quotes, time or calculations. It is not an internet-connected AI.

🔑 Forgot password?

Use "Forgot password?" on the login screen or Settings → Password reset email.
